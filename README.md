# fs-messenger (FreeSynergy.Messenger)

FreeSynergy program (ADR 0018, 0054): one program for mail, chat and agents, encrypted only.
This repo holds the program core `fs-messenger-core`; see `DESIGN.md` for what it does and does not do yet.

Try it: `cargo run -p fs-messenger-core --example demo`
